Profile

技術と経営を、ひとつの線でつなぐ。

AI、半導体、ロボティクス、宇宙、自動運転、製造のような先端技術領域では、技術だけでも事業だけでも前に進みません。必要なのは、開発・営業・資本政策・組織・撤退判断までを一続きで見られる視点です。

LeapMindでは、エッジAIや組込みAIを含む深層学習技術の社会実装を目指し、ソフトウェアスタックからAI推論アクセラレータIP「Efficiera」、そして次世代半導体開発までを一貫して推進しました。ハードウェアとソフトウェアの両方を理解したうえで、プロダクトとして成立させることにこだわってきました。

その経験を土台に、ロボティクス、宇宙、自動運転、製造など、研究開発・現場導入・事業化が密接に絡むテーマでも、技術と経営の間にある論点整理を支援してきました。

同時に、事業責任者として、顧客開拓、アライアンス、採用、財務、人事、資金調達まで幅広く担ってきました。技術の難しさを経営の言葉に翻訳し、意思決定に必要な材料へ変えることが強みです。

2024年には、事業の継続だけでなく解散・清算という難しい判断も経験しました。だからこそ、勝ち筋を描くことと同じくらい、リスクを見極めて正しく舵を切ることの重要性を理解しています。

深い技術領域ほど、「続ける力」と「止める判断力」の両方が求められます。その両面を現場で経験してきたことが、今の支援の土台です。

How I work

関わり方のイメージ

  • 顧問・アドバイザーとして、経営陣や事業責任者の意思決定を継続支援
  • 特定テーマの短期プロジェクトで、戦略整理から実行プランまで集中的に支援
  • 講演・対談・勉強会などで、先端技術とディープテック経営の知見を共有
どんな準備があると相談しやすいですか？

まだ情報が揃っていなくても大丈夫です。現状の課題、悩んでいる判断、関係者、期限感が分かるだけでも、論点整理から一緒に始められます。

どのフェーズの会社や組織に向いていますか？

AI、半導体、ロボティクス、宇宙、自動運転、製造領域を扱うディープテック系スタートアップ、新規事業を持つ大企業、官公庁や産業系プロジェクトなど、技術と経営の接続が難しい場面と相性があります。

スポット相談と継続支援のどちらも可能ですか？

可能です。単発の壁打ち、戦略整理の短期支援、継続的なアドバイザリーなど、テーマと必要な深さに合わせて柔軟に設計できます。

向いているご相談

技術と経営の間に論点があるケース

  • 技術の強みはあるが、事業としての勝ち筋や優先順位が定まりきっていない
  • AI、ロボティクス、宇宙、自動運転、製造領域の新規事業をPoCで終わらせず、実装や展開まで見据えて進めたい
  • 続ける・変える・止めるを含めて、重要な意思決定を整理したい

別の進め方が合うこともあります

実装だけを短納期で切り出したいケース

  • 仕様が固まっていて、助言や論点整理なしで受託開発だけを依頼したい
  • 助言や論点整理より、まずは手を動かす人材だけを探している
  • 経営や事業の前提整理より、単純な制作リソース補充を優先したい

実務を伴う支援は、必要な成果物と関与範囲を確認したうえで組み込みます。

進め方はどのように決めますか？

最初に、意思決定の重さ、関与頻度、成果物、期間を確認します。そのうえで、事業上の価値と責任範囲が明確になる形へ整理します。

単発の壁打ちは依頼できますか？

可能ですが、論点が明確で意思決定につながる場合に限ってお受けしやすいです。継続支援や短期プロジェクトの前段として、課題の見立てを合わせる使い方が向いています。

問い合わせ前に何を共有すればよいですか？

プロジェクトの背景、意思決定したいこと、関係者、期限、期待する成果が分かると早いです。守秘が必要な情報は、初回のやり取りで扱い方を確認してから進めます。
