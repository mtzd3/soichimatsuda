Profile

技術と経営を、ひとつの線でつなぐ。

AIや半導体、エッジAI、組込みAIのような資本集約型の領域では、技術だけでも事業だけでも前に進みません。必要なのは、開発・営業・資本政策・組織・撤退判断までを一続きで見られる視点です。

LeapMindでは、エッジAIや組込みAIを含む深層学習技術の社会実装を目指し、ソフトウェアスタックからAI推論アクセラレータIP「Efficiera」、そして次世代半導体開発までを一貫して推進しました。ハードウェアとソフトウェアの両方を理解したうえで、プロダクトとして成立させることにこだわってきました。

同時に、事業責任者として、顧客開拓、アライアンス、採用、財務、人事、資金調達まで幅広く担ってきました。技術の難しさを経営の言葉に翻訳し、意思決定に必要な材料へ変えることが強みです。

2024年には、事業の継続だけでなく解散・清算という難しい判断も経験しました。だからこそ、勝ち筋を描くことと同じくらい、リスクを見極めて正しく舵を切ることの重要性を理解しています。

深い技術領域ほど、「続ける力」と「止める判断力」の両方が求められます。その両面を現場で経験してきたことが、今の支援の土台です。

01 / Build

技術の芯をつくる

深層学習モデル設計、エッジAI・組込みAI実装、AIアクセラレータ、TSMC 12nm/28nmでのSoC開発まで、研究と製品の間を埋める実装に強みがあります。

02 / Scale

市場と組織へ広げる

200社超との共創、Toyota・三井物産・Intelなどとの協業、$45Mの調達、100名規模の組織運営を通じて、技術を事業へ伸ばしてきました。

03 / Decide

難しい局面で決める

PMF再設計、資本政策、採用、M&Aや清算を含む意思決定まで。前向きな挑戦だけでなく、終わらせ方の設計にも向き合ってきました。

How I work

関わり方のイメージ

  • 顧問・アドバイザーとして、経営陣や事業責任者の意思決定を継続支援
  • 特定テーマの短期プロジェクトで、戦略整理から実行プランまで集中的に支援
  • 講演・対談・勉強会などで、AIとディープテック経営の知見を共有
どんな準備があると相談しやすいですか？

まだ情報が揃っていなくても大丈夫です。現状の課題、悩んでいる判断、関係者、期限感が分かるだけでも、論点整理から一緒に始められます。

どのフェーズの会社や組織に向いていますか？

エッジAIや組込みAIを扱うディープテック系スタートアップ、新規事業を持つ大企業、官公庁や産業系プロジェクトなど、技術と経営の接続が難しい場面と相性があります。

スポット相談と継続支援のどちらも可能ですか？

可能です。単発の壁打ち、戦略整理の短期支援、継続的なアドバイザリーなど、テーマと必要な深さに合わせて柔軟に設計できます。
