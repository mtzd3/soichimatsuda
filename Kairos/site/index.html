Platform

企業ごとのAgentic AIを、データ主権の内側で育てる。

01

業務Agentを作る

Domain Pack、Knowledge Graph、Tool APIを組み合わせ、会計、調達、製造、公共業務などのAgentic AIを構築します。

02

評価で鍛える

承認、却下、例外処理、業務成果を評価データへ変換し、モデル、Policy、Workflowを継続更新します。

03

オンプレで動かす

機密データを外へ出さず、企業内または国内専用設備の計算基盤で推論、評価、軽量学習を回します。

Offering

ソフトウェアから計算基盤まで、全部を一社で接続する。

Build

Agentic AI構築

企業の業務手順、権限、例外処理、外部システム接続を読み込み、実行可能なAgentとWorkflowへ落とし込みます。

Learn

強化学習ループ

業務outcome、専門家の修正、承認結果をreward signalとして回収し、評価とモデル更新へ戻します。

Govern

主権実行基盤

Policy、provenance、監査ログ、rollbackを標準化し、AIが現実の状態を変える条件を企業側が握ります。

Run

オンプレ計算基盤

GPU、Model Gateway、Vector/Graph基盤、評価workerを企業内に配備し、データを管理境界の外へ出しません。

Learning Loop

強化学習ループを、各企業の業務成果から回す。

  1. Observe

    会話、文書、業務イベント、tool callをCanonical Eventとして記録する。

  2. Evaluate

    成功、失敗、専門家修正、承認却下をEvaluation Busで評価する。

  3. Reward

    業務成果、リスク、監査適合性をreward signalとして設計する。

  4. Update

    Domain Pack、adapter、retrieval、Policy、Workflowを更新する。

  5. Deploy

    署名、canary、rollbackを通して企業内環境へ再配備する。

On-prem Compute

主権はSaaS機能だけではなく、計算の置き場所まで含めて設計する。

02

03

Sovereign Data Plane

Canonical Event、Knowledge Graph、Policy、provenance ledger

04

On-prem Compute

Model Gateway、GPU/専用compute、Vector/Graph store、監査worker

Deployment

小さく導入し、企業固有のAI能力として蓄積する。

Phase 1

対象業務、データ境界、承認フロー、評価指標を定義する。

Phase 2

Domain PackとAgentを実装し、現場データで評価基盤を作る。

Phase 3

オンプレ計算基盤へ移し、学習・評価・配備ループを企業内で回す。
