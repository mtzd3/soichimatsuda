# Kairos Logo Assets

Primary assets:

- `kairosai-logo.svg`: horizontal logo for normal light surfaces.
- `kairosai-logo-mark.svg`: Sovereign Stack mark for compact UI and icons.
- `kairosai-logo-lockup.svg`: logo plus concept line for covers and proposal title pages.
- `kairosai-logo-reverse.svg`: reverse logo for dark surfaces.
- `kairosai-logo-mono.svg`: single-color logo for restricted print or stamps.
- `kairosai-logo-sheet.svg`: preview sheet for quick review.

Note: asset filenames currently keep the `kairosai-logo*` prefix for compatibility with existing references.

## Concept: Sovereign Stack

Kairos provides three offerings that support each other:

1. AgenticAI systems: the top layer delivered to users.
2. General-purpose foundation model development: the middle layer that supports the systems.
3. Compute infrastructure development: the bottom layer that supports both model development and deployed systems.

The mark expresses this as an asymmetric supported stack:

- The bottom rail is compute infrastructure.
- The middle rail is foundation model development.
- The top rail is AgenticAI systems.
- The orange path is the load path / Kairos edge that binds the stack and turns capability into deployment.

## Trend-Aligned Rules

- Stack, not pillars: the three offerings are hierarchical and mutually supporting, not merely parallel.
- Pixel-sharp geometry: square caps, hard joins, and 8px-grid proportions.
- High-contrast minimal palette: `Stack #20242A` plus `Load Path #E45B1B`.
- Responsive identity: mark, horizontal logo, lockup, reverse, and mono variants.
- Motion-ready construction: bottom rail appears first, then middle, then top, then the orange load path climbs through the stack.
- Micro-detail anchor: the rails narrow as they move upward, encoding support from infrastructure to product.

Usage:

- Keep clear space around the mark at least equal to 50% of the mark height.
- Prefer the primary logo on `#FAF9F7` or white surfaces.
- Use the reverse logo on `#20242A` or similarly dark backgrounds.
- Use the mono logo only when color reproduction is constrained.
