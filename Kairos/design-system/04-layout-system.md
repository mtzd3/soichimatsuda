# 04. Layout System

## 1. Standard chrome

### Action title block

- 左端に8px相当の縦アクセント
- タイトルは1〜2行
- タイトル下に細い横罫線
- タイトル枠の高さを固定せず、2行時は下部全体を押し下げる
- タイトルの上へ本文を置かない

### Lead

- タイトル直下
- 1〜2行
- そのページの読み方または前提を示す
- タイトルの言い換えだけにしない

### Footer

- 出典: 左下
- 機密区分: 中央下、必要な資料のみ
- ページ番号: 右下
- フッター帯は使用しない

## 2. Content zones

標準ページ:

- Header zone: 18〜22%
- Evidence zone: 68〜74%
- Footer zone: 6〜8%

本文をフッター領域へ侵入させない。

## 3. Alignment

- タイトル、lead、主図表の左端を揃える
- 反復要素は上端と下端を揃える
- カラム間のガターを均一にする
- 中央揃えは表紙、大型数値、短いラベルに限定
- 日本語本文は左揃え

## 4. Panels

パネルを使う条件:

- 内容が独立して比較できる
- 境界が意味を持つ
- 見出しの階層が同じ

標準:

- 2〜3パネル
- 最大4パネル
- 5パネル以上は工程または分類専用

改善されたパネル:

- 影なし
- 1px border
- 上部色面または左keyline
- 内側余白20〜24px

## 5. So-what band

用途:

- 結論の再掲ではなく、示唆、判断、含意
- ページ下部の8〜12%以内
- ink背景＋白文字、または淡色面＋ink文字

一枚に一つまで。すべてのページへ置かない。

## 6. Number tags

- 工程、優先順位、参照番号にだけ使う
- `01`, `02`形式
- ラベル幅を揃える
- 装飾目的の連番は禁止

## 7. Icons

- 既存の統一アイコンセットだけを使う
- 1ページ最大6個
- 絵文字は禁止
- ×、✓は補助記号としてのみ使い、ラベルを併記する

## 8. Images

- 人物写真は背景が整理され、視線がテキスト側と競合しないもの
- 設備写真は場所・対象・日時が説明できるもの
- 画像の上へ長文を置かない
- 顔写真＋経歴は、代表実績3〜5点へ編集する
- 画像を証拠として使う場合、キャプションと出典を付ける

## 9. Dense layouts

高密度ページで削らないもの:

- タイトル
- Lead
- 見出し階層
- 出典
- 行間

先に削るもの:

- 重複説明
- 形容詞
- 装飾
- 二重の囲み
- 不要な凡例

## 10. Page rhythm

archetypeとは別に、各ページへリズムを指定する。

| Rhythm | 役割 | 使い方 |
| --- | --- | --- |
| `anchor` | 結論や判断を固定する | 主張は一つ。大型タイトル、単一数値、短い補足を優先 |
| `dense` | 根拠を読ませる | 表、チャート、比較を使う。出典と読み方を近くに置く |
| `breathing` | 理解の間を作る | 章扉、問い、単一図解。カードグリッドにしない |

`dense`は2枚まで連続可、3枚目は`anchor`または`breathing`へ変える。同じarchetypeが4枚続く場合は、面積配分、主役、またはページリズムを変える。

## 11. Editable grouping

SVGまたは生成PPTXを使う場合、要素は意味単位でグループ化する。

- `background`、`header`、`footer`、`logo`、`rule`はchromeとして扱う
- 本文側は`title`、`chart`、`table`、`callout`、`step-1`など意味で命名する
- 1ページの主要content groupは3〜8個を目安にする
- animationを使わない場合でも、編集しやすさのためにgroupを残す

## 12. Anti-patterns

- 全要素が箱に入っている
- タイトルよりパネル見出しが強い
- 3種類以上の影
- 1ページに6色以上
- 太い枠線
- 狭いカラムへ長文
- 上下左右で余白が異なる
- 末尾の1行だけが次のカラムへ回る
- 意味単位で選択できない一枚画像スライド
