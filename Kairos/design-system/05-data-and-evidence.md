# 05. Data and Evidence

## 1. Evidence hierarchy

証拠は次の優先順位で扱う。

1. 一次データ
2. 公的統計・公式資料
3. 査読論文・標準
4. 企業公式情報
5. 信頼できる二次分析
6. 仮説・推論

事実と推論を同じ書式で置かない。

## 2. Evidence labels

| Label | 意味 |
| --- | --- |
| `FACT` | 確認済みの事実 |
| `ESTIMATE` | 前提に基づく推計 |
| `HYPOTHESIS` | 検証前の仮説 |
| `INFERENCE` | 複数事実から導いた示唆 |
| `DECISION` | 組織として採用する判断 |

必要な場合、出典付近または図表タイトルに表示する。

## 3. Chart selection

| 問い | 推奨 |
| --- | --- |
| 時間でどう変わったか | 折れ線、縦棒 |
| 何が大きいか | 横棒 |
| 内訳は何か | 積上げ棒 |
| どこに分布するか | 散布図、ヒストグラム |
| 何と何が関係するか | 散布図 |
| どの案が優れるか | decision matrix |
| 数字を正確に比較したい | table |

円グラフは3区分以内で、構成比が主題の場合だけ使う。

## 4. Chart rules

- 3D禁止
- 主系列だけaccent
- 他系列はgray
- 凡例より直接ラベルを優先
- 軸、単位、期間を明記
- 棒グラフは原則ゼロ始点
- 予測値は実績と線種または面で区別
- 重要な変化点へ注釈を置く
- タイトルは発見を書く

## 5. Tables

- 本編: 最大6行×5列
- 付録: 最大12行×7列を目安
- ヘッダーはink背景またはsoft-fill
- 縦罫線は原則なし
- バンド行はごく淡く
- 数値は右揃え
- 文章は左揃え
- 推奨行は左keylineまたはBold
- 表の下に一文のimplicationを置く

## 6. Numbers

- 重要数値は一枚最大4個
- 単位を数値から離さない
- 小数桁を統一
- 期間を明記
- 比較対象または基準値を添える
- 桁の大きい数値は読みやすく変換する

例:

- `1,560,000,000円` → `15.6億円`
- `$160,000,000` → `$160M`

## 7. Estimates

推計には次を併記する。

- 基準日
- 入力値
- 計算式
- 除外項目
- 感度

本編には結果と主要前提だけを置き、詳細式は付録へ置く。

## 8. Sources

出典表記:

> Source: 組織名, 資料名, 公表日, URL, accessed YYYY-MM-DD

複数出典:

> Sources: [1] ... [2] ...

出典のない比較値、架空の数値、装飾用のダミーグラフは禁止。

## 9. Uncertainty

不確実性は隠さず、次で表現する。

- range
- scenario
- confidence
- sensitivity
- gate

単一の点推計だけで重大判断を示さない。
