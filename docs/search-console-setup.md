# Search Console

公開URLは `https://mtzd3.github.io/soichimatsuda/`。現行コンテンツは1ページ。

1. URL-prefix propertyとして登録する。
2. 管理画面で発行された所有権確認タグを必要に応じて `index.html` のheadへ追加する。値を推測しない。
3. `https://mtzd3.github.io/soichimatsuda/sitemap.xml` を送信する。
4. URL検査でトップのインデックスを確認する。

検索クエリ例: 松田総一、AI 半導体 技術顧問、スタートアップ 経営相談、起業 資金調達 採用 相談。

`/soichimatsuda/robots.txt` はホスト直下の `/robots.txt` ではないため、サイトマップ発見をそれだけに依存させない。旧テーマページはトップへ転送し、サイトマップへは含めない。
