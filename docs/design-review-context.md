# デザインレビューの前提

MTZ-285の改訂目的は、松田総一の技術と創業経営の実体験を伝え、問い合わせへつなげること。

- 主語は本人。2012年からのAI経験と10年以上の創業・経営経験を中心にする。
- 技術から、ファイナンス、人事・労務、法務、採用、組織運営まで、相談範囲を具体的に示す。
- Kairosは考え方と視覚表現の参照。会社の製品・開発計画を本人の提供実績として転記しない。
- クリーム色の背景、黒い主CTA、オレンジの補助アクセント、細い罫線、影を使わない面、Noto Sans JP、広い余白を使う。
- 構成: Hero → 本人の経験と考え方 → note/Xの発信 → 相談テーマ → 公開根拠のある実績 → 進め方 → 本人紹介 → FAQ → Contact。
- PC/モバイルで横溢れ、見出しの読みやすさ、アンカー位置、メール表記とSNS導線を確認する。
- 1ページのタイトル・説明文・canonical・構造化データ・内部リンク・サイトマップを整合させる。

最終指示: 1ページ、下層コンテンツなし、フォームなし。note/Xが主要導線。ヘッダーは文字のみで旧ロゴを廃止。メールは[アット]表記で、操作時だけ組み立てる。
