# 松田聡一 - コンサルティングサイト

AI・深層学習技術および事業アドバイザーの松田聡一のコンサルティングサイトです。

## 🚀 プロジェクト概要

このサイトは、AI・深層学習分野での豊富な経験と実績を持つ松田聡一のプロフェッショナルなコンサルティングサービスを紹介するWebサイトです。

### 主な特徴

- **テック・ミニマリズムデザイン**: 技術的信頼性を表現する洗練されたデザイン
- **SEO最適化**: 検索エンジンとAI検索に最適化された構造
- **レスポンシブ対応**: モバイル・タブレット・デスクトップ全対応
- **高速パフォーマンス**: Vite + React による高速な静的サイト

## 🛠 技術スタック

- **フロントエンド**: React 19, TypeScript, Tailwind CSS
- **ビルドツール**: Vite
- **バックエンド**: Express.js (開発用)
- **UI コンポーネント**: Radix UI, Framer Motion
- **パッケージマネージャー**: pnpm

## 📁 プロジェクト構造

```
consulting-site/
├── client/                 # フロントエンドアプリケーション
│   ├── public/            # 静的ファイル
│   └── src/               # ソースコード
├── server/                # バックエンドサーバー
├── shared/                # 共有定数・型定義
├── patches/               # パッケージパッチ
└── docs/                  # ドキュメント
```

## 🚀 開発環境のセットアップ

### 前提条件

- Node.js 18+
- pnpm 10+

### インストール

```bash
# 依存関係のインストール
pnpm install

# 開発サーバーの起動
pnpm dev

# ビルド
pnpm build

# プロダクション環境での起動
pnpm start
```

## 📝 利用可能なスクリプト

- `pnpm dev` - 開発サーバーを起動
- `pnpm build` - プロダクション用にビルド
- `pnpm start` - プロダクション環境でサーバーを起動
- `pnpm preview` - ビルド結果をプレビュー
- `pnpm check` - TypeScriptの型チェック
- `pnpm format` - コードフォーマット
